# 闪动校园 传感器控制

纯 native Zygisk 传感器控制模块，支持步数/加速度/陀螺仪/旋转矢量数据注入与同步。

## 功能更新

- **v1.3.5**：WebUI 界面优化（状态看板折叠）；移除多实例互斥（支持多实例同步仿真）；新增传感器冲突监测（仅针对目标包名，保护隐私）。
- **v1.3.4**：日志信息增强（设备名、指纹、系统信息）。
- **v1.3.3**：修复 WebUI 并发写配置冲突（原子写盘）；解决 Android 16 后台冻结与双开强同步问题。

## 使用说明

1.  通过 KSU 安装模块并重启。
2.  启动闪动校园应用。
3.  浏览器访问 `http://127.0.0.1:8888` (或自动探测端口) 控制仿真。
4.  若遇步频异常，请通过 WebUI 顶部的“传感器冲突监测”查看日志。

## 技术栈
*   纯 Native (C++)，不依赖 LSPosed / ClassLoader / 内存 Dex。
*   基于 Zygisk 实现 PLT/Inline Hook。
*   提供 HTTP API 供 WebUI 交互。
